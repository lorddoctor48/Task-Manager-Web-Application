# Task-Manager-Web-Application 

### Developed by Lloyd Ryu 

## Overview
A web-based system to improve task management, enhance productivity and provide a more user-friendly interface.

## Features

### Add new task
- Users can create tasks (via a form) with a task name, due date, priority level (low, medium or high) and optional consultant (obtained from a provided list of Gelos staff members).

### Display tasks
- Tasks should be shown in a clear list or table, including name, due date, priority level and consultant. Each task should include controls to complete or delete it:

### Complete task 
- Users can mark tasks as complete. When a task is completed, it should remain visible but displayed with strikethrough formatting.
### Delete task
- Users can remove tasks no longer needed. CRUD

### Search tasks
- Users can look up tasks by task name to display results or ‘Task not found’.

## Technology Stack
- HTML
- CSS
- JavaScript
- AsyncStorage

## Setup Instructions

### Clone the repository
- Open up Windows Powershall
- git clone https://github.com/lorddoctor48/Task-Manager-Web-Application.git
- cd Task-Manager-Web-Application

### Running the application
- Open the root project directory
- Use the live server extension in VS Code to run the website
